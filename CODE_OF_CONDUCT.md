# Código de conduta

Contribuições devem manter respeito, colaboração e precisão técnica. Não publique informações pessoais, chaves, material de autenticação nem dados de usuários. Reporte problemas de segurança de modo privado conforme `SECURITY.md`. Ataques pessoais, ameaças e exposição indevida de dados não são aceitáveis.
