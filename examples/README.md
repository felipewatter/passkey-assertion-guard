# Exemplos

Execute `npm run demo` para observar uma autenticação de um desafio em memória com chave ES256 descartável, seguida de rejeição de replay e de uma assinatura de chave desconhecida.

Para demonstrações de Ed25519, regras de contadores, cópias de estado e flags BE/BS, consulte os testes em `test/assertions.test.js`.

Não há credenciais reais nem mocks de cadastro WebAuthn armazenados aqui. **Não publique as chaves privadas de um autenticador real no repositório.**
